# 3D Interactive Programmer's Apartment

Welcome to my virtual space! This is an immersive 3D portfolio project built with **Three.js** that simulates a programmer's multi-room apartment. You can walk around as a robot, explore the different rooms, and interact with various objects.

This project was created to blend web development with interactive 3D graphics, showcasing skills in JavaScript, Three.js, and creative coding.

## ✨ Features

- **Multi-Room Exploration**: Navigate between three distinct areas: the Office, the Living Room, and the Library.
- **Third-Person Controller**: Control a robot character with classic `WASD` for movement and mouse for camera control.
- **Interactive PC**: Approach the desk in the office and interact with the central monitor to browse a live website (my portfolio!) embedded within the 3D scene.
- **Functional TV**: Walk up to the TV in the living room to play videos from a playlist, with on-screen controls for play/pause, mute, and changing videos.
- **Teleportation Doors**: Seamlessly transition between rooms using interactive doors.
- **Dynamic Environment**:
    - A window with a procedurally animated, futuristic cityscape.
    - A cozy, animated fireplace in the library.
    - Custom-generated procedural textures for rugs, code screens, and more.
- **Rich Details**: The scene is filled with custom-modeled furniture, posters, and lighting to create a vibrant, neon-lit atmosphere.
- **Post-Processing**: `UnrealBloomPass` is used to give emissive materials a beautiful, glowing effect.
- **Mobile Fallback**: The experience gracefully degrades on mobile devices, presenting a welcome screen with a link to the standard 2D portfolio to ensure a good user experience for everyone.

## 🛠️ Technologies Used

- **Three.js**: The core 3D library for rendering and scene management.
- **GSAP (GreenSock)**: Used for smooth camera animations, especially for the PC zoom-in feature.
- **HTML5 & CSS3**: For the UI, splash screen, and interactive overlays.
- **JavaScript (ES6 Modules)**: For all the application logic, character controls, and interactivity.
